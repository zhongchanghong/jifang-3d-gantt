# 机房3D可视化实例项目甘特图

> 周期：2026年10月9日（节后）～ 12月11日，共9周 ｜ 团队：项目经理 + 1开发 + 3新工 ｜ 技术路线：Three.js / Web

**在线访问**：https://zhongchanghong.github.io/jifang-3d-gantt/

单文件、零依赖的交互式项目甘特图，部署在 GitHub Pages 上。

## 功能

- **悬停提示**：任务条上显示任务全名、负责人、起止日期、工期
- **阶段筛选**：点击图例按 5 个阶段显隐
- **人员筛选**：下拉选择项目经理/开发/新工A/B/C，匹配任务高亮、其余淡化
- **今日线**：红色竖线自动定位今天（项目未启动时显示倒计时）
- **里程碑联动**：点击菱形跳转并高亮对应验收标准
- **深色模式**：跟随系统自动切换，也可手动切换（右上角按钮）

## 如何修改计划（不用装任何工具）

1. 在 GitHub 网页上打开本仓库的 [`index.html`](./index.html)，点右上角 **铅笔图标** 编辑
2. 找到 `TASKS` 数组，修改日期（格式 `2026-10-09`）或增删任务
3. 填写提交说明，点 **Commit changes**
4. 约 1 分钟后在线页面自动更新

条形位置、工期、今日线全部由日期自动计算，无需手动画图。

## 数据结构

```js
const TASKS = [
  { phase: 0, name: "任务名称", owner: "负责人", start: "2026-10-09", end: "2026-10-09" },
];
const MILESTONES = [
  { phase: 0, tag: "M1", name: "里程碑名", date: "2026-10-16" },
];
```

`phase` 取值 0-4：启动与资料 / 场景建模 / 交互开发 / 优化与测试 / 演示与验收。
